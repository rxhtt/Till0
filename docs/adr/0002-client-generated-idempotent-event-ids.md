# ADR 0002: Client-Generated Idempotent Event IDs

## Context
Network retries, duplicate requests, and reconnections can submit the same sync payload multiple times.

## Decision
Every domain event generated by a terminal is assigned an immutable, client-generated unique ULID prior to transmission. The server maintains unique constraints on event IDs to deduplicate submissions idempotently.

## Consequences
Replays and duplicate transmissions result in no-op deduplication rather than duplicate ledger entries.
